# 📌 DM Encounter & Loot Toolkit — Project Notes & Roadmap

Per `AGENTS.md` operating guidelines, non-essential ideas or features outside the immediate v1 scope are parked here for future expansion.

---

## 🚀 Later / Post-v1 Ideas

1. **Custom Monster Builder:**
   - Allow DMs to input custom homebrew monsters with custom HP, AC, CR, and actions, storing them in `localStorage`.

2. **Campaign Export Presets:**
   - Export full campaign session prep notes (encounters, loot, initiative order, hazards) as a single downloadable JSON or Markdown file.

3. **Audio / Ambient Soundscape Hooks:**
   - Integrate Web Audio API or royalty-free ambient audio loops (dungeon, tavern, battle, wilderness) triggered by encounter difficulty.

4. **YouTube / Creator Prep Templates:**
   - Pre-formatted script templates for TTRPG content creators explaining encounter design and SRD rule breakdown videos.
